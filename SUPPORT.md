# Finglish Keyboard Support

For help, bug reports, or privacy questions, open a public issue in the
[Finglish Keyboard issue tracker](https://github.com/shining44/FinglishKeyboard/issues/new).

Please include the app version, iOS or iPadOS version, device model, and steps
to reproduce the problem. Do not post passwords, private messages, or other
sensitive text. If a screenshot is useful, crop or redact personal content
before attaching it.

## Setup

1. Open **Settings** on the device.
2. Go to **General → Keyboard → Keyboards → Add New Keyboard**.
3. Select **Finglish Keyboard**.
4. Use the globe key while typing to switch keyboards.

Full Access is not required.
